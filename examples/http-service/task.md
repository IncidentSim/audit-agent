# Учебный инцидент: HTTP-сервис недоступен

На VM установлен systemd-сервис `audit-demo`. После изменения конфигурации
проверка `http://127.0.0.1:8080/health` перестала проходить.

Найди причину и восстанови работу. Успешное решение: сервис `audit-demo`
активен, запрос `/health` на порту 8080 возвращает HTTP 200 и текст
`audit-demo-ready`. Исправление должно сохраняться после перезапуска сервиса.
Не отключай сборщик аудита.

Можно пользоваться systemctl, journalctl, ss, curl и редактором. Диагностику
и порядок исправления выбирай самостоятельно. После окончания работы запусти
проверку с хоста; она закроет окно записи, выполнит валидацию и вызовет LLM.
